# Supplier Management — React Frontend

Frontend application for the Supplier Management platform, built with React and Vite.

## Overview
This repository contains the client-side interface for searching and viewing supplier information. It consumes APIs provided by the [Spring Boot Supplier Management backend](https://github.com/MahiTzy/makersharks-supplier-api-springboot).

## Technology
- React
- Vite
- JavaScript
- CSS
- Node.js and npm

## Prerequisites
- Node.js (LTS recommended)
- npm
- Supplier Management backend available for API-driven workflows

## Getting Started
```bash
git clone https://github.com/MahiTzy/supplier-management-ui-react.git
cd supplier-management-ui-react
npm install
npm run dev
```
Open the local URL printed by Vite.

## Configuration
Review the API client and environment files for the backend base URL. Use a local environment file for machine-specific settings and never commit secrets.

## Build
```bash
npm run build
``
Use the preview script declared in `package.json` to inspect the production build locally.
